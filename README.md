CyberGUI

A WinForms cybersecurity awareness chatbot built in C# for PROG6221.

Features
- Keyword-based responses on cybersecurity topics
- Memory recall — remembers your name and favourite topic
- Sentiment detection — responds based on how you are feeling
- Typing animation for a realistic chat experience
- Voice greeting on startup
- Coloured chat interface with ASCII logo

Topics You Can Ask About
- Password security
- Phishing
- Safe browsing
- Privacy
- Malware
- Scams
- WiFi safety
- Viruses

How To Run
1. Clone the repository
2. Open `Cyberbot.slnx` in Visual Studio
3. Build and run the project

Built With
- C# .NET
- Windows Forms (WinForms)
